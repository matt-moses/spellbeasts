# What the build has added since the PRD

The PRD (`spelling-bee-creature-game-prd.md`) is the approved starting point. These changes were requested during the build; the game follows them where they differ from the PRD.

| Area | PRD | Now |
|---|---|---|
| Lands | 6 regions | **12** (added Crystal Caves, Sunset Dunes, Starfall Isles, then Harvest Hollow, Lantern Harbor, Wishing Ruins). Unlocks continue at level 12 / 44 mastered, 14 / 47, 16 / 50, then 18 / 53, 20 / 56, 22 / 60 (the last three need a word list bigger than 50) |
| Creatures | 18 (+6 arena-only in Phase 2) | **36** Nest creatures (3 per land), 108 SVGs. Egg prices continue 90, 105, 125, 145, 165, 190 |
| Trail | 30 steps per region, flat | Longer each land: 30, 32, 34 ... 52 steps (progressively harder), 492 in all |
| Map | One screen | A wide, **scrollable** world (drag, swipe, arrows, keyboard) that follows the token |
| Trophies | 14 | **45**, including care trophies and one for opening all 12 lands; star tiles award trophies when opened |
| Care and play | none | Four meters per creature (fed, clean, loved, fun), berries, bath, petting, three mini-games (Berry Catch, Hop Run, Memory Match), a daily "sparkle" gift of 3 crickets. Games cost 3 crickets (1 back for a great game) and the gift needs a practice session that day, so care always leads back to spelling |
| Berries | none | +2 per practice session, +1 per treasure star. Games no longer pay berries |
| Characters | decorative | Tap-to-play: every click runs the next action in a shuffled rotation (animation, sound, effect, speech bubble) |
| Look | plain | A bright park-scene look: chunky buttons, pills, a board-game map with star tiles and a region wheel |
| Order of unlock and step | unspecified | An answer that unlocks a land can already step the token into it |
| Phase 2 Trainer Battles (Arena) | 6 arena-only species; 5 hearts; a win ends the battle | Built. 12 arena-only species (one per land). Hearts scale with the session (10 to 14) so the fight lasts it, and the remaining words are a victory lap. The special move is every third right answer in a row. An unowned egg species joins 25% of the time. The win is saved the moment the last heart goes. Details in `plan.md`. |

Where the PRD's numbers conflict: a brand-new trainer's first session has only **3 words**, because the PRD caps new words at 3 per session and nothing is due yet. That follows the 3-new-words rule rather than the 10-12-word target.
